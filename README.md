## WHAT IT DOES

Single-page portfolio with interactive data visualizations, project modals, dark mode, and contact form.
Built for recruiters and data teams.

```
FEATURES:
├── Interactive dashboard (Chart.js)
├── Project deep-dive modals
├── Skill proficiency bars
├── Learning timeline with animations
├── Testimonials carousel
├── Dark mode toggle
├── Scroll progress indicator
├── Resume download
└── Contact form with validation
```

## SETUP

**RUN LOCALLY:**

```bash
git clone https://github.com/Rahul006-max/portfolio.git

start index.html
```

## CUSTOMIZATION

**UPDATE PERSONAL INFO:**

```html
<!-- index.html line ~87 -->
<h1>Hi, I'm [YOUR NAME]</h1>
```

**CHANGE COLORS:**

```css
/* styles.css line ~1 */
:root {
  --accent-color: #2563eb;
  --accent-secondary: #10b981;
}
```

**ENABLE CONTACT FORM:**

Integrate Formspree, EmailJS, or Netlify Forms. No backend required.
